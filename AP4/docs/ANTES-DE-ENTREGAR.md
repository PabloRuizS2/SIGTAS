# Entrega final

Los archivos principales son RUIZ-PABLO-AP4.pdf, RUIZ-PABLO-AP4-VIDEO.mp4 y SIGTAS-AP4-COMPLETO.zip. El enlace del código es https://github.com/PabloRuizS2/SIGTAS/tree/main/AP4.

1. Mirar el video final completo y comprobar nombre y audio.
2. Subir el PDF y el video al aula; adjuntar el ZIP si la plataforma lo admite o incluir el enlace al código.
3. Si el aula exige un enlace de video en vez de un archivo, cargarlo en el servicio admitido y comprobar que el docente pueda abrirlo.
4. La participación en foros/encuentros se acredita con la actividad personal realizada, no con el código.
5. Para presentar el programa desde VS Code, abrir la carpeta del proyecto, revisar el aviso de confianza del editor, configurar el JDK y los datos locales de `.env`, y ejecutar Main.

Se mantuvo la organización ficticia aprobada en el TP3. No se adjuntaron observaciones docentes adicionales; no se inventaron correcciones.
